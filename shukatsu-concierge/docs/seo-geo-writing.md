## 一次情報とは何か

**一次情報**＝他サイトの要約ではなく、**ここにしかない／元データに近い事実**。検索でも生成AI（GEO）でも、「引用するならこのページ」になりやすい材料です。

二次情報（ニュースの要約だけ・Wikipedia的な一般論だけ）は補助。主軸にしない。

### 終活コンシェルジュ文脈での例

| 種類 | 例 | 載せ方の注意 |
|---|---|---|
| **現場の経験知** | 「病院入院時に保証人を求められる流れ」「施設側が連帯保証と緊急連絡先をどう分けるか」など、相談対応で繰り返し見るパターン | 個人が特定されない抽象度。断定は「よくある」「現場では〜が多い」 |
| **匿名化した解決事例** | 相談経路・止めどころ・先に整えた手続き・結果（既存 jirei / case 型） | 実在個人情報禁止。ダミーまたは十分匿名化。数字はぼかす |
| **自団体の実績・沿革** | 設立年、対応件数の公開範囲、活動実績の年次、ガイドライン対応の自社方針 | 公開済み実績・公式に確認できる数字のみ |
| **自団体のサービス定義** | ささえ／おとも／むかえの範囲、契約の流れ、解約時の注意 | `/service/` `/disclosure/` と矛盾させない |
| **一次ソースへの橋渡し** | 消費者庁・厚労省・法務省のガイドライン／調査の**原典URL・公表日・調査名** | 要約は短く。数値は原典を見てから。リンク切れ確認 |
| **独自の整理表・比較** | 「身元保証と成年後見の役割の違い」「入院と施設で求められることの差」 | 独自の切り口であること。制度断定は要確認 |
| **FAQの短答** | 場面別の1問1答（病院・施設・遠方家族など） | 冒頭で答え、根拠は次の文。FAQPageと整合 |
| **取材・講演・連携の事実** | 地域包括・MSW・紹介会社との連携の仕方（一般化した手順） | 固有名・個人名は許可があるものだけ |
| **料金・契約の公開情報** | 公開している料金表・重要事項の要点 | 非公開・個別見積のみの内容を断定しない |

### 一次情報にならないもの（避け方）

- 他社ブログの焼き直しだけの長文
- 出典のない「必ずこうなる」「誰でもすぐ契約できる」系の断定
- キーワードを並べただけの見出し・メタ描写
- 実在ケースの住所・氏名・病名の組み合わせなど特定されうる詳細

### 「経験」の扱い（E-E-A-T / GEO）

経験は一次情報の中核。ただし **語れる範囲** を守る。

- 書く: 相談の起点、手続きの順序、よくつまずく点、連携先の役割
- 書かない: 実在の氏名、細かい病歴の羅列、資産額の生値、未匿名の時系列
- 弱い例:「丁寧に寄り添い解決しました」
- 強い例:「包括同席のアセスメント → 身元保証契約 → 遺言・死後事務の順で、入所の止めどころを先に外した」

## コラムの書き方チェックリスト

- [ ] タイトルに**場面語**（入院／施設／身寄りなし／遠方 等）が入っている
- [ ] 冒頭1〜2文で**定義か結論**がある
- [ ] 「この記事で分かること」がある
- [ ] 一次情報または経験知が**1つ以上**ある（出典 or 現場パターン）
- [ ] 制度・数値は原典確認、未確認は断定しない・`needs_review`
- [ ] `/mimoto-hosho/` や `/service/` `/faq/` `/contact/` への内部リンク
- [ ] `meta_description` が結論先出し（目安120字）
- [ ] AI下書きなら原則 draft + 要確認。人間承認前に published にしない（ニュース月次自動公開のみ例外: [monthly-news-auto.md](./monthly-news-auto.md)）

推奨見出し例:

1. 定義・結論  
2. よくある場面  
3. 何が止めどころか  
4. 取りうる選択肢（一般論 + 当団体の範囲）  
5. 相談前に整理すること / FAQ  
6. 関連ページ

## 解決事例の書き方チェックリスト

- [ ] タイトルが「課題｜相談経路」で検索意図と一致
- [ ] 冒頭で「誰の・何の悩みがどうなったか」が分かる
- [ ] 状況表 → 課題 → 対応 → 結果 → ポイント
- [ ] 対応に**順序と止めどころ**がある（経験の可視化）
- [ ] 匿名化／ダミー方針を満たす
- [ ] 同テーマのガイド・コラム・FAQへ1本以上リンク
- [ ] 宣伝だけの締めにせず、再現可能なポイントで終える

## GEO（生成AIに引用されやすくする）補足

- **答えを先に、条件を後に**（「〜です。ただし〜」）
- 1見出し1テーマ。長い前置きを置かない
- 固有名詞（団体名・サービス名・公式ガイドライン名）を正確に
- FAQは質問文をユーザーの言い回しに近づける（「病院 身元保証人 いない」系）
- ページ冒頭の要点文は、サイト全体の AnswerLead 方針と揃える
