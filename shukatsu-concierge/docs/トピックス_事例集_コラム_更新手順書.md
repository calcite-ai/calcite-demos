## はじめに：共通の考え方

トピックス・事例集・コラムのいずれも、内容の性質に応じて作成方法は異なりますが、「最終的に公開ボタンを押すのは必ず人（担当者）」という点は共通です。特に相続・成年後見・死後事務など、誤った情報が利用者の不利益に直結しうるテーマについては、AIが生成した文章であっても、内容を必ず確認してから公開してください。

## 1. トピックスの更新手順

トップページの「トピックス」欄は、お知らせや時事情報などタイムリーな情報を担当者が直接入力・公開するコーナーです。承認フローはなく、入力した内容がそのまま公開されます。

1. WordPress管理画面にログインする  
2. 「トピックス」から新規追加を選択する（CPT名は実装時に確定。**既存の「イベント／xo_event」とは別**。xo_eventは踊活レッスン予定用）  
3. タイトルと本文を入力する。日付・カテゴリ等の項目があれば併せて入力する  
4. 内容に誤字脱字や事実誤認がないか確認する  
5. 「公開」ボタンを押す  

※ 承認フローがない分、入力ミスがそのまま公開されます。特に日付・固有名詞・金額等の数字は入力後に必ず見直してください。

## 2. 事例集の更新手順

実際にあった相談事例を、匿名化した上で掲載するコーナーです。担当者がプルダウン形式の項目を選択・入力すると、AIが下書き文章を自動生成します。生成された下書きは担当者が内容を確認・修正してから公開します。

### 入力する項目

| 項目 | 選択肢・内容 |
|---|---|
| 相談者属性 | 本人／ご家族／ケアマネジャー／病院MSW／地域包括支援センター／老人ホーム／紹介会社 |
| 相談カテゴリ（複数可） | 身元保証／入院保証／老人ホーム入居／成年後見／死後事務／相続／生活保護／認知症対応 |
| 年代 | 60代／70代／80代／90代以上 |
| 家族構成 | 独居／配偶者あり／子と同居／子はいるが疎遠／親族なし |
| 対応にかかった期間 | 即日／1週間以内／1ヶ月以内／3ヶ月以内／3ヶ月以上 |
| 主な対応内容（複数可） | 身元保証契約締結／施設入居手続き代行／緊急連絡先対応／死後事務委任契約／財産管理サポート／成年後見制度利用支援 |
| 結果ステータス | 解決・契約継続中／解決・支援終了／他機関へ紹介／継続対応中 |
| 相談の背景・きっかけ | 自由記述（1〜2文） |
| 対応のポイント・工夫した点 | 自由記述（1〜2文） |
| 匿名化確認 | 個人が特定できる情報を含んでいないかの最終確認チェック |

### 操作の流れ

1. WordPress管理画面の事例集入力フォームを開く  
2. 上記のプルダウン項目を選択し、自由記述欄に相談の背景と対応のポイントを入力する  
3. 匿名化確認チェックボックスにチェックを入れる  
4. 送信すると、内容をもとにAIが下書き文章を自動生成する（数分程度かかる場合がある）  
5. 生成された下書きを「事例集」の下書き一覧から開き、内容を確認する  
6. 事実と異なる箇所、不自然な表現があれば修正する  
7. 問題なければ「公開」ボタンを押す  

※ 自由記述が少ないとAI文章も抽象的になりがちです。背景・工夫した点はできるだけ具体的に書いてください。

## 3. コラムの更新手順

高齢者福祉・制度改正等のニュースをもとにした記事です。週1回、自動的にAIが下書きを作成する仕組みになっているため、担当者が最初から書く必要はありません。担当者の役割は「できあがった下書きを確認・修正して公開する」ことです。

### 自動生成の流れ（担当者は操作不要）

1. 週1回、高齢者福祉・介護保険・終活関連のニュースや制度改正情報が収集される  
2. AIが記事下書きを作成し、WordPressに「下書き」として保存される  
3. 新しい下書きができると、担当者にメールまたはSlackで通知が届く  

### 担当者が行う操作

1. 通知を受け取ったら、WordPress管理画面の「コラム」から下書き一覧を開く  
2. 新しく追加された下書きを開き、内容を確認する  
3. 事実関係・数字・制度名称に誤りがないか確認する（一次情報で裏取り）  
4. 表現を整える、実務に基づく補足を加える等、必要な修正を行う  
5. 問題なければ「公開」。修正が必要なら下書きのまま保存  

---

## 困ったときの連絡先

操作方法が分からない場合や、システムの不具合（下書きが生成されない、通知が届かない等）が疑われる場合は、日野研太まで連絡してください。
