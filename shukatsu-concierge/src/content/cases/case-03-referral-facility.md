**施設入居が決まっていても、親族が身元保証人を引き受けられないと、退院・入居が進みません。** この解決事例は、施設紹介会社からの相談を起点に、ご家族の理解のもと身元保証契約を進めたケースです。

## この事例で分かること

- 親族が保証を拒否する場面での進め方
- 退院・施設入居を急ぐときの面談の速さの意味
- 入居中の保証と、死後の備えをセットで考える選択肢

## 相談内容

脳出血で入院中の男性です。左片麻痺があり、退院後に入居する施設は決まっていますが、妻も娘も身元保証人にはならないと拒否しています。他に頼れる親族がいません。身元保証会社を使うことにはご家族も理解を示しており、説明と契約の依頼がありました。

## ご本人の状況（概要）

| 項目 | 内容 |
|---|---|
| 年齢 | 86歳 |
| 介護認定 | 要介護4 |
| 病歴 | 脳出血、左片麻痺 |
| ADL | 一部介助 |
| 経済状況 | 年金（月約17万円） |
| 本人の意向 | 延命治療は望まない |
| 家族の意向 | 施設利用料などは年金額の範囲で収めたい。亡くなったあとのことも任せたい |

## 課題

1. **入居先は決まっているが、身元保証人がいない**
2. **退院期限があり、迅速な面談・契約が必要**
3. **ご家族への経過報告も求められている**

## 対応内容

1. **施設紹介会社の同行依頼を受け、病院で説明**  
   妻立会いのもと、支援内容を説明しました。
2. **身元保証契約の締結**  
   ご納得のうえで身元保証契約を締結し、施設長へ報告しました。
3. **入居準備と死後の備え**  
   入居に伴う手配を進め、亡くなったあとの手続きについても整理し、関連する契約につなげました。
4. **ご家族への報告**  
   支援の経過をご家族に随時報告しました。

## 結果

- スムーズな退院・施設入居につながった
- 入居中の身元引受・連帯保証の受け皿ができた
- 緊急時の連絡先と、死後の手続きの見通しが立った

## ポイント

- ご家族の代わりとして、入居中の身元引受・連帯保証をサポートする
- 緊急時の連絡先となり、迅速に対応する
- お亡くなりになったあとの各種手続きも代行できる体制を整える
