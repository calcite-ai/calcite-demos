# WordPress 実装キット（ログイン前準備）

本番WPログイン前に用意した、トピックス／事例／コラム用の実装一式です。

## 中身

```
wordpress/
├── README.md                 ← このファイル
├── plugins/shukatsu-content/ ← CPT・タクソノミー・公開ガード
├── acf-json/                 ← ACFフィールド定義（インポート用）
└── docs/REST下書き仕様.md     ← RESTで下書きを投げる仕様
```

関連ドキュメント:

- [`../docs/CPT-ACF設計.md`](../docs/CPT-ACF設計.md)
- [`../docs/トピックス_事例集_コラム_更新手順書.md`](../docs/トピックス_事例集_コラム_更新手順書.md)

## ログイン後の手順（短い）

1. **バックアップ**（All-in-One WP Migration 等）
2. 可能なら **ステージング** に先に入れる
3. `plugins/shukatsu-content/` を `wp-content/plugins/shukatsu-content/` にアップロードして有効化
4. **ACF**（Advanced Custom Fields）を導入  
   - Pro なら `acf-json/` をテーマまたはプラグイン配下の `acf-json` に置き自動同期  
   - または カスタムフィールド → ツール → インポート で JSON を取り込む
5. **設定 → パーマリンク** で「変更を保存」（リライトルール更新）
6. 管理画面に「トピックス」「解決事例」「コラム」等が出ることを確認
7. 事例で匿名化OFFのまま公開すると下書きに戻ることを確認
8. Author専用ユーザー＋アプリパスワードを発行し、REST下書きを1件テスト

## 注意

- 現行テーマは TCD `switch_tcd063`。フロント表示テンプレはテーマ側の追加作業が別途必要（このキットはデータ構造まで）
- PHP 7.3 は古い。可能なら PHP 8.1+ へ上げてから本番適用
- `xo_event`（踊活）はこのキットでは触らない
- 匿名化ガードは ACF が入っていないと効かない
