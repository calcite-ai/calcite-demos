## 含むもの

### ページ構成（最大6ページ）

| ページ | 内容 |
|---|---|
| TOP | キャッチ、事業概要、CTA |
| 会社概要 | 会社名、所在地、代表、事業内容 |
| サービス/商品 | 主要サービス 3〜6項目 |
| お問い合わせ | 電話 / メール / 簡易フォームのいずれか |
| プライバシーポリシー | テンプレベース |

### 差し替え

- 会社名 / 屋号
- ロゴ（提供がある場合）
- 電話・メール・所在地・営業時間
- 事業内容テキスト
- サービス名 / 商品名
- 写真 **最大5点**
- Googleマップ埋め込み（住所がある場合）

### 本番公開（切替）※v1.1で標準同梱

次のいずれか **1方式**（フォームで選択）:

| 方式 | 内容 |
|---|---|
| **S** 既存レンタルサーバーへ設置 | 御社の現行サーバー（エックスサーバー・ConoHa等）へ静的HTMLを配置。旧トップを差し替え |
| **D** DNS／ドメイン接続 | 御社ドメインの向き先を変更し、新サイトを公開 |

含む作業の上限:

- 切替作業 **1回**（日程は先方とメールで調整）
- 公開確認（PC・スマホ）
- 旧サイトの退避（可能な範囲でバックアップ案内 or 旧indexのリネーム）

含まない（切替まわり）:

- 新規ドメイン取得・新規サーバー契約
- メールアカウントの移行・設定
- 旧サイト全ページのアーカイブサイト化・リダイレクト設計（5ページ超）
- SSL証明書の新規発行でパネル操作以外の複雑な認証局作業
- 複数ドメイン・サブドメインの一括移行

接続情報が揃わない間は切替に着手しない（差し替えのみ先行可）。

### デザイン・導線・SEO

- デモ準拠デザイン（配色・レイアウト・フォント変更なし）
- 問い合わせ導線 **1つ**
- title / meta description / OGP基本
- Organization / LocalBusiness 相当の構造化データ

### 修正

- **1回まで**（差し替え誤字・表記・写真・文言の軽微修正、切替後の軽微な表示修正）
- **10箇所以内**

### 納品物

- 本番公開済みURL（御社ドメイン）
- 確認用URL（切替前の社内確認用・任意）
- ソース一式
- 差し替え済み画像
- 簡易運用メモ
- 修正1回の案内

- 修正2回目以降、オンライン打ち合わせ、訪問
- 切替方式の途中変更（S→D等）に伴う再作業一式

## お客様提出物

詳細: [`demo_buyout_intake_form.md`](./demo_buyout_intake_form.md)

### 必須（48時間以内・コンテンツ）

- 会社名 / 屋号、代表者名
- 電話、メール、所在地、営業時間・定休日
- 事業内容（200〜800字）
- 掲載サービス名（3〜6項目）
- 問い合わせ導線の希望（電話 / メール / 簡易フォーム）
- **希望デモ案 A/B**

### 必須（公開切替・接続情報）

- 公開したいドメイン（例: `example.co.jp`）
- 切替方式（S または D）
- 方式S: サーバー会社名・FTP/ファイルマネージャ等の接続情報（または設定代行可能な権限付与）
- 方式D: ドメイン管理画面へのアクセス、または指定DNSレコードを設定できる担当
- 希望切替日（目安で可）

### 任意

- ロゴ（PNG / SVG / AI）
- 掲載写真（最大5点）
- 旧サイトURL / パンフ
- GoogleビジネスプロフィールURL

素材・接続情報未提出の間は納期カウントしない。  
7日未提出は制作保留。
