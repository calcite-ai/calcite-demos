# 「機会損失になっています」などの断定は使わない。

# 使える切り口の例:
#   ・問い合わせ導線が弱い
#     「電話番号はあるが、スマホでタップ発信できない」→ 電話したいときに一手間増える
#     「フォームはあるが、第一画面にCTAが見えない」→ 次の行動が分かりにくい
#   ・セキュリティ / 信頼
#     「httpのまま（鍵マークが付かない）」← httpsか必ず確認 → 警告で不安になりやすい
#   ・スマホ表示
#     「viewportがなく画面幅に合わない」→ 見づらく閉じられやすい
#   ・更新
#     「更新が止まって見える」→ いま依頼してよいか判断しづらい

#   ・PSIスコアを測っていないのに「遅い」と断定
