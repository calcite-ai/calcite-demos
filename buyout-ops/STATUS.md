## 今日いちばん重要な発見

**「21社に送って0返信」ではなく「21社に送って誰もデモを開いていない」だった。**

SendGrid上はクリック率31%と出ていたが、Email Activity で宛先別に割ったところ、
クリックは**全て自分宛の控え（旧BCC）**で、営業先は6社中6社が0だった。
開封率0%も「開かれていない」ではなく、送信ヘッダで**開封追跡を切っていた**ため
測っていなかっただけ。

対処済み:
- 開封追跡を ON（`sendgrid-smtp-headers.mjs`）
- 控えを BCC → **追跡なしの別メッセージ**に分離（`archive-copy.mjs`）
  - BCC は同一メッセージなので追跡設定を分けられない
  - 控えの宛先が営業先と一致したら送らないガード付き（二重送信防止）
- 状況確認: `gh workflow run buyout-sendgrid-status.yml`

**次に見るべきもの**: 9/8 以降の送信で初めて営業先だけの開封率が取れる。
- 開封あり・クリックなし → 件名は通っている。本文かデモの見せ方の問題
- 開封もなし → 件名か迷惑メール判定。デモを磨いても届かない
