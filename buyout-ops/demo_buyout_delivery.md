## 目的

66,000円プラン（差し替え＋既存ドメイン本番公開）の納品品質を **毎回同じ手順** で担保する。  
自動化は `tools/qa-check.mjs` ＋ 人の最終確認（スマホ390px）＋切替確認。

---

## 制作〜納品フロー

```
素材＋切替情報受領 → 差し替え → QA → 人の最終確認 → 確認用公開 → 本番切替 → 納品メール → 修正1回待ち
```

| 段階 | 担当 | 成果物 |
|---|---|---|
| 差し替え | 🤖＋👤 | ローカルHTML / ビルド成果物 |
| QA | 🤖 | `qa-check` レポート |
| 最終確認 | 👤（390px目視） | OK/NGメモ |
| 確認用公開 | 🤖 | カルサイト側確認URL（任意） |
| 本番切替 | 👤＋🤖 | 御社ドメインで公開 |
| 納品 | 👤→🤖 | 納品メール＋ソース |

## Phase 1: 差し替え完了チェック（素材照合）

フォーム内容と実装が一致しているか。

- [ ] 会社名 / 屋号が正式表記どおり
- [ ] 代表者名・担当者名（掲載する場合）が正しい
- [ ] 電話番号・メールアドレスがフォームと一致
- [ ] 住所・郵便番号が正しい
- [ ] 営業時間・定休日が反映されている
- [ ] 事業内容が200〜800字の範囲内（超過は要約済み）
- [ ] サービスが3〜6項目（超過分は採用していない）
- [ ] 写真が **5点以内**
- [ ] 問い合わせ導線がフォーム指定どおり（tel / mail / 簡易フォーム）
- [ ] ロゴ未提出時は文字ロゴで問題ないことを確認

**66,000円の範囲外を入れていないか（必須）**

- [ ] デザイン変更していない
- [ ] ページ追加していない（最大5ページ）
- [ ] 新規コピーライティングをしていない（整文のみ）
- [ ] 切替は1ドメイン・1方式のみ

## Phase 2: 半自動QA（`qa-check.mjs`）

差し替え後、納品前に必ず実行。

```bash
cd ~/claude/02_hp-sales
node tools/qa-check.mjs demos/<案件ディレクトリ>/
```

または単一HTML:

```bash
node tools/qa-check.mjs demos/<案件>/index.html
```

### 必須パス（FAILが1つでもあれば修正して再実行）

| カテゴリ | 内容 |
|---|---|
| レスポンシブ | viewport meta あり |
| 文字コード | UTF-8 |
| SEO | title あり |
| 画像 | alt あり |
| リンク切れ | 内部リンク切れなし |
| スマホ固定バー | 下部固定バー（tel/mail）あり |
| Google Maps | ダミー座標なし（住所がある場合） |

### 警告（WARN）の扱い

| WARN | 対応 |
|---|---|
| meta description なし | 納品前に追加 |
| tel: なし（電話導線を選んだ場合） | 必ず追加 |
| 画像タグなし | プレースホルダで可。意図的ならメモ |

**qa-check が FAIL 0 になるまで納品しない。**

## Phase 3: 人の最終確認（必須）

ワークスペースルール: **幅〜390px** で主要ページを確認。

### 確認ページ（最大5）

- [ ] TOP
- [ ] 会社概要
- [ ] サービス
- [ ] お問い合わせ
- [ ] プライバシーポリシー

### スマホ（〜390px）

- [ ] 表が横スクロール強制になっていない
- [ ] 文字切れ・はみ出し・極端な余白の偏りなし
- [ ] ボタン・リンクがタップしやすい
- [ ] 固定バーが画面を塞ぎすぎていない
- [ ] ヒーローが画面を塞ぎすぎていない

### デスクトップ（1280px目安）

- [ ] レイアウト崩れなし
- [ ] ナビ・フッターが機能している

### コンテンツ・信頼

- [ ] プライバシーポリシーに **会社名** が入っている
- [ ] デモ透かし・「サンプル」「イメージ」表記が **消えている**
- [ ] ダミー電話・ダミー住所が残っていない
- [ ] OGP / title / description が会社名ベース

### 導線

- [ ] tel: タップで発信（電話導線の場合）
- [ ] mailto: またはフォームが動作（メール/フォームの場合）
- [ ] 主要CTAから問い合わせページへ到達できる

## Phase 4: 確認用公開 → 本番切替（標準同梱）

方針（`demo_buyout_plan.md` v1.1）: **既存ドメインでの本番公開が本体に含まれる**。

### 4a. 確認用（任意・短期間）

- [ ] カルサイト側URLで先方確認（PC・スマホ）
- [ ] 修正希望があれば修正1回の枠内で反映（切替前が望ましい）

### 4b. 本番切替（必須）

フォーム指定の **方式S** または **方式D** のどちらか1つ。

| 方式 | チェック |
|---|---|
| **S** 既存サーバー設置 | FTP/ファイルマネージャ接続成功・ドキュメントルート特定・旧index退避・新ファイル配置・https表示 |
| **D** DNS接続 | 指定レコード案内 or 代理設定・伝播確認・https表示 |

共通:

- [ ] 接続情報を安全に扱い、作業後はログにパスワードを残さない
- [ ] 本番URL（御社ドメイン）で全ページが開く
- [ ] 問い合わせ導線が本番でも動く
- [ ] スマホ390pxで本番URLを再確認
- [ ] 公開URLを記録（リスト `delivered_url` = 本番ドメイン）
- [ ] ソース一式を zip 等で用意
- [ ] 差し替え済み画像を同梱フォルダに整理

接続情報が未提出の場合: 差し替えまで完了し、切替は情報受領後に着手（納期カウント停止）。

## Phase 5: 納品

テンプレ: `templates/email_demo_buyout_7_delivery.txt`

送るもの:

1. **本番公開URL**（御社ドメイン）
2. ソースの受け渡し方法（Drive / メール添付方針）
3. 修正1回の案内（10箇所以内）
4. 含まれないものの再確認（デザイン変更等は別料金）

納品後:

- [ ] リスト status → `delivered`
- [ ] 納品日を記録
- [ ] 7日後アップセルは任意1通（`demo_buyout_inbox.md`）

---

## 修正1回（納品後）

### 含む

- 表記・誤字
- 電話 / メール / 住所
- 写真差し替え
- 文言の軽微変更
- **10箇所以内**

### 含まない → 別見積もり

- デザイン変更
- ページ追加
- 新規文章
- 2回目以降（5,500円・税込）

修正後も **Phase 2〜3 を短縮版** で再実行（変更箇所＋主要ページ）。
